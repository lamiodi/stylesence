    34→## API contract (v1 — all agents follow exactly)
    35→
    36→All JSON. Errors: `{ "error": "message" }` + status. Success wraps payload in named keys (e.g. `{ products, total, page, perPage, facets }`).
    37→
    38→**Storefront**
    39→- `GET /api/categories` → `{ categories: [{ id, slug, name, tagline, imageUrl, productCount }] }`
    40→- `GET /api/products?category=&q=&size=&color=&minPrice=&maxPrice=&sort=featured|newest|price-asc|price-desc|rating&page=1&perPage=12` → `{ products: [{ id, slug, name, subtitle, price, compareAtPrice, primaryImage, colors:[{name,hex}], sizes:[string], rating, reviewCount, isNew }], total, page, perPage, facets: { colors:[{name,hex,count}], sizes:[{size,count}], priceRange:{min,max} } }`
    41→- `GET /api/products/[slug]` → `{ product: { …card fields, description, material, care, details:[string], category:{slug,name}, images:[{url,alt}], variants:[{id,size,color,colorHex,stock,sku}], rating, reviewCount, reviews:[{id,author,rating,title,body,createdAt}], related:[{slug,name,price,primaryImage}] } }` (404 unknown/inactive)
    42→- `POST /api/products/[slug]/reviews` `{author,email,rating(1-5),title,body}` → `{ review, status:"PENDING" }`
    43→- Cart (`ss_cart` cookie, lazy-create):
    44→  - `GET /api/cart` → `{ cart: { items:[{ id, qty, variant:{id,size,color,colorHex,stock}, product:{slug,name,price,primaryImage} }], subtotal, itemCount } }`
    45→  - `POST /api/cart` `{variantId, qty}` → same cart shape
    46→  - `PATCH /api/cart` `{itemId, qty}` (0 removes) → cart
    47→  - `DELETE /api/cart?itemId=` / `?clear=1` → cart
    48→- `POST /api/checkout` `{email,fullName,phone,address,city,state,notes?,shippingMethod:"standard"|"express"}` → validates stock, decrements, creates order (status `PAID` — dev placeholder payment), clears cart → `{ order:{ orderNumber, total } }`
    49→- `GET /api/orders/[orderNumber]` → `{ order: { orderNumber, status, email, fullName, address, city, state, country, phone, shippingMethod, shipping, subtotal, total, createdAt, items:[{productName,productSlug,size,color,imageUrl,unitPrice,qty}] } }`
    50→- `POST /api/newsletter` `{email}` → `{ ok:true }` (dedupe, zod email)
    51→- `GET /api/journal` → `{ posts:[{slug,title,excerpt,category,coverImage,publishedAt,readTime}] }`
    52→- `GET /api/journal/[slug]` → `{ post:{ …, body } }` (paragraphs separated by `\n\n`, `## ` headings)
    53→
    54→**Admin** (cookie `ss_admin`; everything except login returns 401 `{error:"Unauthorized"}`)
    55→- `POST /api/admin/login` `{email,password}` → sets cookie; `{ admin:{name,email,role} }`; 401 on bad creds; naive rate limit
    56→- `POST /api/admin/logout` → `{ ok:true }`
    57→- `GET /api/admin/me` → `{ admin }` | 401
    58→- `GET /api/admin/stats` → `{ revenue:{total,last30}, orders:{total, byStatus:{PAID,PROCESSING,SHIPPED,DELIVERED,CANCELLED}, last30Series:[{date:"YYYY-MM-DD",revenue,orders}], recent:[{orderNumber,fullName,email,total,status,createdAt,itemCount}] }, products:{total,active,lowStock:[{productName,variant:{size,color},stock}]}, reviews:{pending,approved,avgRating}, subscribers, customers }`
    59→- `GET /api/admin/products` (all incl inactive, w/ variants+images+summed stock) → `{ products }`
    60→- `POST /api/admin/products` full payload incl. `variants:[{size,color,colorHex,stock}]`, `images:[{url,alt}]`, `details` string → `{ product }`
    61→- `PATCH /api/admin/products/[id]` partial (name, subtitle, price, compareAtPrice, isActive, isFeatured, categoryId, description, material, care, details, variantStocks:[{id,stock}]) → `{ product }`
    62→- `DELETE /api/admin/products/[id]` → `{ ok:true }`
    63→- `GET /api/admin/orders` → `{ orders:[{…order, items:[…]}] }` newest first
    64→- `PATCH /api/admin/orders/[id]` `{status}` (validate enum) → `{ order }`
    65→- `GET /api/admin/reviews?status=` → `{ reviews:[{…, productName, productSlug}] }`
    66→- `PATCH /api/admin/reviews/[id]` `{status}` → `{ review }`; `DELETE` → `{ ok:true }`
    67→- `GET /api/admin/subscribers` → `{ subscribers:[{id,email,source,createdAt}] }`
    68→- `GET /api/admin/customers` → `{ customers:[{email,name,orderCount,lifetimeValue,lastOrderAt}] }` (derived from orders)
