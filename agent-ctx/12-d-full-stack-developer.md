Work Log:
- API (src/app/api/products/route.ts — only API file touched): GET /api/products accepts `inStock` ("1"|"true" enable; anything else, incl. "0", is ignored) and filters the result rows to products with ≥1 variant stock > 0. No response-shape change → no src/lib/types.ts edits needed (facets verified byte-identical with/without the param).

No Radix trigger → openerRef effect restores focus to the expand button on close.
